{# Whether each key is configured, what it costs when it is not, and how to set it. **The gap this fills.** RepoBridge degrades correctly without either key -- that is the design, and it is why nine milestones passed without anyone noticing that *nothing tells a person the keys exist*. Without a GitHub token you are on 60 requests an hour, and the first sign is a rate-limit error that names the limit but not the fix. Without a Gemini key every run ends with `not_configured` in the summary section, which reads like a malfunction rather than a setting. **Nothing here comes near a value.** The context carries two booleans and three variable *names*; no key, no prefix, no length, no masked form. A masked value is still a disclosure -- it confirms length and leaks the first characters -- so there is no "sk-…abcd" here and there must never be. `_key_status()` in `main.py` is where that is enforced, and `test_no_key_value_can_reach_a_template` is what keeps it enforced. Expects `keys`. #}
